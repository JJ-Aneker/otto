Manual de uso

Cómo sacar partido a Otto, paso a paso.

Primeros pasos

El agente se abre con una pantalla de login: entra con tu email y contraseña, o crea una cuenta nueva.

Cada perfil es un cliente o negocio, con su propia voz, base de conocimiento, WordPress y claves de IA. Cámbialo desde el selector de arriba. En Configuración completa el perfil, conecta WordPress y pega tu API Key del proveedor de IA que prefieras.

Generar un post

1. Selecciona la temporada (opcional) — filtra el calendario por Primavera, Verano, Otoño o Invierno para ver los temas más relevantes en cada época.

2. Elige un tema del calendario — haz clic sobre cualquier tema para seleccionarlo. Los marcados como «Escrito» ya se generaron antes.

3. O usa "Tema libre" — escribe cualquier tema personalizado, añade un enfoque y elige la longitud del post.

4. Pulsa «Generar» — en 20-30 segundos tendrás el post listo con SEO, texto, HTML y sugerencias de imágenes.

Las pestañas del resultado

SEO — título optimizado (55-60 caracteres), slug URL, meta descripción, keyword principal, keywords secundarias, categoría y tags para WordPress.

Post — texto completo en formato legible para revisar el contenido.

Editar — editor de texto donde puedes modificar el post directamente. Pulsa "Actualizar HTML" para aplicar los cambios.

HTML — código HTML listo para pegar en WordPress. Puedes copiarlo con el botón "Copiar HTML".

Preview — vista previa del post con las imágenes insertadas, tal como se verá en WordPress.

Imágenes — fotos sugeridas automáticamente de tu biblioteca de WordPress. Las 3 primeras se preseleccionan. Haz clic para seleccionar o deseleccionar. Pulsa "Insertar en el post" para distribuirlas a lo largo del contenido.

Biblioteca de imágenes

Antes de generar posts, carga las imágenes una vez por sesión pulsando "Cargar imágenes de WordPress". El agente descarga las fotos de tu biblioteca y las clasifica automáticamente por categoría.

Usa los filtros para ver solo Newborn, Embarazo, Familias, etc. Puedes buscar por nombre de archivo con el buscador.

El botón "Etiquetar con IA" analiza los nombres de archivo y asigna categoría y alt text SEO automáticamente a todas las imágenes.

Publicar en WordPress

Ve a la pestaña WordPress. Las credenciales se rellenan automáticamente con tu sesión. Puedes elegir entre:

Borrador — el post se guarda sin publicar para revisarlo en WordPress antes.

Publicar directamente — el post se publica inmediatamente en el blog.

Programar — elige fecha y hora de publicación futura.

Una vez publicado, aparece un enlace directo para verlo en WordPress.

Gestionar el calendario

En la pestaña Calendario puedes gestionar todos los temas editoriales:

Añadir temas — usa el formulario de la derecha. Indica nombre, categoría, temporada y enfoque.

Reordenar — arrastra los temas con el icono de puntos para cambiar su orden. Las semanas se actualizan automáticamente.

Importar CSV — sube un archivo CSV con columnas: nombre, categoria, temporada, angulo.

Proponer con IA — Claude analiza los temas existentes y sugiere 8 nuevos temas relevantes para tu negocio.

Historial

Cada post generado puede guardarse pulsando "Guardar". El historial muestra estadísticas de posts guardados, publicados, borradores y posts de este mes.

Desde el historial puedes cargar un post anterior para editarlo o republicarlo, copiar el HTML, ver el enlace en WordPress o eliminarlo.

Consejos de uso

Frecuencia recomendada: 1 post cada 2 semanas siguiendo el calendario editorial.

Imágenes: carga la biblioteca al inicio de cada sesión para que las sugerencias funcionen correctamente.

Revisión: siempre revisa el post en la pestaña "Post" antes de publicar. La IA es muy buena pero tú conoces mejor a tus clientes.

Preview: usa la vista previa para comprobar cómo quedan las imágenes distribuidas antes de publicar.

Guarda los posts: pulsa "Guardar" antes de publicar para tener un historial de todo el contenido generado.
